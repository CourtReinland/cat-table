# Sakura build order

Every new game, system, or hero asset. Do not skip leftover. **Invent last.**

1. **Market** — what successful genre games do on screen.
2. **Leaders** — what they are built with.
3. **Acquire** — Unity / Fab / Godot / itch / Kenney / GitHub / Synty first (buy / license; no ripping).
4. **Leftover** — the unique strength of **this** title.
5. **Code only that leftover.**
6. **Fast art pipes** — Steph cat pipe [`tools/character-pipe/SOP.md`](../../tools/character-pipe/SOP.md); img2threejs in `tools/img2threejs/`.
7. **Asset list per class.**
8. **Model those practices** before inventing.
9. **If still no kit, invent and ship.**

Stay **three.js** in this repo. Do not start a Unity project for Cat Top Sim.

Leftover is the work. Everything else is acquire-or-pipe.
